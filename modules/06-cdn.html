How a CDN Works

A Content Delivery Network (CDN) is a geographically distributed network of proxy servers and their data centers. The goal is to provide high availability and performance by distributing the service spatially relative to end-users.

When a user requests content from a website that uses a CDN, the CDN redirects the request to a server that is geographically closest to the user. This reduces latency and improves the user experience.

Push vs. Pull Zones

  • Pull Zone: The CDN pulls content from your origin server when it's requested for the first time. The content is then cached on the CDN's edge servers for subsequent requests. This is the most common type of CDN.
  • Push Zone: You upload your content directly to the CDN's storage. This is useful for large files that don't change often, such as video files or software downloads.

Benefits of a CDN

  • Improved Performance: By caching content closer to users, CDNs can significantly reduce page load times.
  • Increased Availability: CDNs can handle traffic spikes and protect against DDoS attacks.
  • Reduced Load on Origin Server: By serving content from the cache, CDNs reduce the load on your origin server.
