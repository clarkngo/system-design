Types of Distributed Storage

  • Object Storage: Data is managed as objects. Each object includes the data itself, a variable amount of metadata, and a globally unique identifier. Examples: Amazon S3, Google Cloud Storage.
  • Block Storage: Data is stored in blocks, which are fixed-size chunks of data. This is used by storage area networks (SANs) and is suitable for databases and other transactional workloads. Examples: Amazon EBS, Google Persistent Disk.
  • File Storage: Data is stored in a hierarchical structure of files and folders. This is what you typically interact with on your personal computer. Examples: Network Attached Storage (NAS), Amazon EFS.

HDFS (Hadoop Distributed File System)

HDFS is a distributed file system designed to run on commodity hardware. It is highly fault-tolerant and is designed to be deployed on low-cost hardware.

Key features of HDFS:

  • Large Data Sets: HDFS is designed to support very large files.
  • Streaming Data Access: HDFS is built around the idea that the most efficient data processing pattern is a write-once, read-many-times pattern.
  • Fault Tolerance: HDFS is designed to detect faults and to automatically and quickly recover from them. Data is replicated across multiple nodes to protect against data loss.
