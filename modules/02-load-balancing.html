What is a Load Balancer?

A load balancer is a device that acts as a reverse proxy and distributes network or application traffic across a number of servers. Load balancers are used to increase capacity (concurrent users) and reliability of applications.

Layer 4 (L4) vs. Layer 7 (L7) Load Balancing

Load balancers can operate at different layers of the OSI model.

  • L4 Load Balancer: Operates at the transport layer (e.g., TCP, UDP). It makes routing decisions based on the source and destination IP addresses and ports, without inspecting the content of the traffic. It's very fast and simple.
  • L7 Load Balancer: Operates at the application layer (e.g., HTTP). It can inspect the content of the traffic, such as HTTP headers or cookies. This allows for more intelligent routing decisions, such as routing a user to the same server they were on previously (sticky sessions) or routing based on the URL path.

Load Balancing Algorithms

There are several algorithms for distributing traffic:

  • Round Robin: Each server gets a turn in a cyclical order. It's simple but doesn't account for server load.
  • Least Connections: The load balancer sends traffic to the server with the fewest active connections. This is a more intelligent approach that accounts for server load.
  • IP Hash: The load balancer calculates a hash of the client's IP address and uses it to determine which server to send the request to. This ensures that a user is consistently sent to the same server.
  • Weighted Round Robin: Some servers are given a higher weight than others, and they receive a proportionally larger share of the traffic. This is useful if you have servers with different capacities.
